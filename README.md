# 읽기 Pace — TOPIK II 読解速度トレーナー

やさしい韓国語を一定のペースで読み、内容確認を保てる速度を段階的に上げるブラウザアプリです。PC・スマートフォンの両方に対応しています。

## 起動

```bash
npm install
npm run dev
```

本番用ファイルは `npm run build` で `dist/` に生成されます。

## GitHub Pagesで公開する

このリポジトリには、テスト・ビルド・GitHub Pages公開を行う
`.github/workflows/deploy-pages.yml` が含まれています。

1. GitHubへリポジトリを作成し、既定ブランチを `main` としてソースをpushします。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. `main` へのpush、またはActions画面の手動実行で公開されます。テストやビルドに失敗した版は公開されません。

`https://<user>.github.io/<repository>/` の `<repository>` 部分はビルド時に自動設定されます。
ユーザーサイト（`<user>.github.io`リポジトリ）では `/` になります。プロジェクトに独自ドメインを割り当てる場合は、ActionsのRepository variableに `VITE_BASE_PATH` を作り、値を `/` にしてください。

GitHub Pagesサイトは公開情報です。ソースを非公開リポジトリに置けるプランでも、通常のPagesサイトまで非公開になるとは限りません。

## 教材を追加する

教材は [`src/data/passages.json`](src/data/passages.json) で管理しています。配列に次の形式のオブジェクトを追加すると、文章選択へ自動的に表示されます。語節数は `text` の表示本文から実行時に計算するため、手入力は不要です。

```json
{
  "id": "unique-id",
  "order": 13,
  "title": "日本語タイトル",
  "titleKo": "한국어 제목",
  "topic": "話題",
  "level": "1–2級",
  "text": "韓国語の本文です。文は句点で分けます。",
  "questions": [
    {
      "id": "unique-id-q1",
      "prompt": "질문은 무엇입니까?",
      "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "answer": 0,
      "evidenceSentence": 0,
      "explanation": "結果画面に表示する短い解説"
    },
    {
      "id": "unique-id-q2",
      "prompt": "두 번째 질문은 무엇입니까?",
      "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "answer": 1,
      "evidenceSentence": 1,
      "explanation": "2問目の短い解説"
    }
  ]
}
```

- `answer` は0始まり（0〜3）です。
- `evidenceSentence` も0始まりで、正解の根拠になる本文の文番号です。
- 各文章には4択問題を2問入れてください。
- `npm test` でID、語節数、文分割、選択肢数、正解位置などを検証できます。

本文の日本語訳は [`src/data/translations-ja.json`](src/data/translations-ja.json) に、同じ `passageId` と文数で追加します。結果画面では設問の根拠文と全文レビューに使用されます。

## 記録

設定、練習履歴、無音実測値はブラウザの `localStorage` に自動保存されます。端末を替えるときは記録画面からJSONをバックアップし、新しい端末で読み込めます。旧形式の配列ログも読み込み時に現行形式へ移行します。

- 記録は外部サーバーへ送信されません。端末・ブラウザ・サイトのオリジンごとに別管理です。
- JSON読込は2MB、練習履歴5,000件、無音実測1,000件を上限とし、内容確認後に現在の記録へ結合します。
- 記録画面から履歴、無音実測メモ、設定を初期化できます。
- 任意メモには氏名、健康情報、連絡先などの個人情報を入力しないでください。

## 公開時の安全性

- 外部API、アカウント、広告、アクセス解析は使用していません。
- `Content-Security-Policy` と `no-referrer` をHTMLで設定しています。
- GitHub Actionsは必要最小限の権限を使い、利用するActionをコミットSHAで固定しています。
- Dependabotがnpm依存関係とGitHub Actionsを週次確認します。
- `.env`、秘密鍵、証明書はGitの追跡対象から除外しています。
- `VITE_`で始まる環境変数もブラウザ向けコードに含まれ得るため、秘密情報を設定しないでください。

本アプリは非公式の自主学習用ツールで、TOPIKおよび運営機関とは関係ありません。収録教材は公式問題の転載ではありません。教材を追加する場合も、自作または公開許諾を得た本文・設問・訳文だけを使用してください。

## 主な実装

- 韓国語TTSと文単位ハイライト
- TTSが使えない場合のハイライトモードへの自動フォールバック
- 壁時計・発話時間・文間空白・起動待ちの分離計測
- 過去5回の音声セッションによるTTSペース較正
- 2問の理解度ゲートと次回ペースの自動調整
- 正誤、正解、本文根拠、日本語訳をまとめた回答レビュー
- 履歴から過去の回答レビューを再表示し、誤答だけに絞り込む復習導線
- 最新結果から復習待ちを自動判定し、優先教材をホームへ提案
- 教材の話題別に理解度を集計する苦手傾向表示
- 文単位で表示を切り替えられる本文・日本語訳レビュー
- 30〜110語節/分の到達域表示と無音実測ベースライン
- 端末への自動保存、履歴ダッシュボード、JSONバックアップ・旧形式移行

Chrome系ブラウザを推奨します。利用可能な韓国語音声はOSとブラウザ環境に依存します。
